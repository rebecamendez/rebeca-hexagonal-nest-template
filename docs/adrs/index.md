## ADR Process

1. Create a new ADR from the [template](template.md).
2. Name the file `XXXX-title.md` with the next available number.
3. Add it to this index.
4. Submit it for review.
5. Update the status to Accepted once approved, or to Deprecated or Superseded when the decision changes.
